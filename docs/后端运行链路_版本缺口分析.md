## 一、后端运行链路（当前部署版）

```
┌─────────────────────────────────────────────────────────┐
│  Railway 容器启动                                         │
│  → node dist/server.js                                  │
├─────────────────────────────────────────────────────────┤
│  1. PrismaService.connect() — SQLite 数据库连接         │
│  2. express.static() — 检查 frontend/dist（分离部署不serve）│
│  3. app.listen(PORT) — API 服务启动（3001）              │

┌─────────────────────────────────────────────────────────┐
```
